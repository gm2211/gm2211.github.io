01 details · Argos

Argos watches a set of repos, hands each ready piece of work (a bead) to a Codex or Claude Code worker in its own git worktree, and runs one durable lifecycle per bead: lint, tests, QA, approval gates, merge, deploy and cleanup, with the evidence recorded. A localhost dashboard, installable as a phone app, shows what is running, what is waiting on you, what shipped and what it cost, and lets you settle real trade-offs with one tap. Work is ordered by dependencies and priority, and an idle system is designed to spend $0 on LLM calls.

  • Rust core with SQLite state: one durable lifecycle per bead, from worktree to deploy and close
  • Decisions inbox holds only real trade-offs, with tap-to-approve gates and per-bead and daily spend ceilings
  • Dependency-aware queue plus a live map of every host, bead loop and agent

02 details · grove

grove runs CI builds, deploys and coding-agent sessions on Macs you already own, inside Tart VMs that Nomad schedules and only your Tailscale tailnet can reach. Each VM packs many jobs through its own Nomad client, which gets around Apple's two-VM limit; a pool can be sealed so its VMs reach the public internet and nothing at home; and a new Mac joins by running one command and being approved from the Fleet page or a /join link and QR. A Go control plane serves the HTTP API, CLI, embedded React UI and an MCP server, and Argos, my agent orchestrator, reads the fleet and places its private-repo CI, deploys and agent sessions on it.

07 details · Corto

Corto is a self-piloting model sailboat: I took an RC sailboat, removed the RC controls, and wired its rudder and sail servos to a Raspberry Pi with GPS and a wind speed and direction sensor. The boat's navigator turns the bearing to the next mark and the wind angle into rudder and sail trim, and a second Pi with knobs steers it by hand over LoRa. The web app is built to show that real boat live: position, heading, wind, rudder and sheet over LoRa, with a link indicator that fades as reports go stale, plus steering and a course you can send to it. A simulator runs the same navigator on modelled wind and current as a test bench, so changes are tried on land first.

  • Hardware: an RC sailboat with its receiver removed, a Raspberry Pi driving the rudder and sail servos, GPS, a wind speed and direction sensor and a LoRa radio
  • The app is built to show the real boat over LoRa: position, heading, wind, rudder and sheet, with link-state fading, manual steering and a course sent to the boat
  • A simulator test bench runs the boat's own navigator on modelled wind and current, so autopilot changes are tested before the water

Specify keeps product intent in one small, versioned YAML spec: behaviors with stable IDs, plus the user's exact words attached as source quotes. 20 details · Trim Lab

An interactive trainer for sail trim on the Colgate 26 sailboat. Every control line has a slider, and an approximate steady-state model (segment aero, a two-element vortex panel method and a heel and leeway force balance) updates boat speed, heel, weather helm and a trim-balance score as you pull. A Babylon.js 3D view runs a position-based cloth simulation for the sails, with wind-dye streamlines drawn from the solved circulation, and the app also has line guides, concept cards and a deck of 66 doctrine-checked drills.

  • Sails fold, flog and luff in the browser: position-based cloth in Babylon.js with a wind-driven boom and jib clew
  • Per-slider trim indicators and a coordinate-descent 'perfect trim' solver show where each line should sit for the wind
  • Boat modelled in Blender from photo references; the entire app ships as one self-contained page built by a Python script

21 details · ECG Studio

A single-page teaching tool that pairs 3D anatomical heart models with live ECG traces. The Simulator lets you pick a conduction problem (bundle branch blocks, WPW, AV block, an AV re-entry loop) and watch activation spread through a see-inside His-Purkinje network on one clock while the paper-calibrated lead trace changes; the Lead explorer maps nine scenarios, including six infarct territories, onto a torso with electrodes and per-lead ABNORMAL flags, and both halves have a quiz mode. Plain JavaScript and three.js with no build step; the heart and torso meshes are Human Reference Atlas models (CC BY 4.0) credited in-app.

  • Pick a conduction problem and watch activation spread through a see-inside His-Purkinje network
  • Six infarct territories light an illustrative heart region while abnormal leads get flagged
  • Quiz modes in both views: inspect the beat, pick the mechanism or mark the abnormal strips, get scored

22 details · Pier 25 Float Plan

A single-file web app that pulls NWS forecasts and marine advisories, NOAA tidal currents, measured wind from nearby stations and NEXRAD radar, then turns them into a GO / CAUTION / NO-GO verdict for a chosen departure time on the Hudson. It suggests which way to head first against the current, runs a sail simulator of the route, and generates a ready-to-file float plan with a compact plan code.
